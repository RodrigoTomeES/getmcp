# Package Map — Key Files

## `@getmcp/core` (`packages/core/src/`)

| File         | Purpose                                                                                                                                                                                                                                                                                                                                                              |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schemas.ts` | All Zod schemas: `StdioServerConfig`, `RemoteServerConfig`, `ServerConfig`, `CanonicalMCPConfig`, `RegistryEntry`, `AppId`, `ManifestServerEntry`, `ProjectManifest`, `RegistryAuthMethod`, `RegistrySource`, `RegistryCredential`. Shared `ArgumentVariableSchema` and `ArgumentSchema` extracted from duplicated `packageArguments`/`runtimeArguments` definitions |
| `types.ts`   | TypeScript types inferred from Zod; `ConfigGenerator` and `AppMetadata` interfaces (`configPaths: string \| null` for project-scoped, `globalConfigPaths: PlatformPaths \| null` for global-scoped, `requiresRestart?: boolean`); exported `PlatformPaths` type and `supportsBothScopes()`, `getDefaultScope()` utility functions                                    |
| `utils.ts`   | Type guards (`isStdioConfig`, `isRemoteConfig`) and `inferTransport()`                                                                                                                                                                                                                                                                                               |

## `@getmcp/registry` (`packages/registry/`)

| File                         | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data/official-servers.json` | Manually curated list of official (first-party) MCP server `officialName` values (reverse-DNS)                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `src/index.ts`               | Registry engine: loads `data/servers.json`, validates via Zod, exposes `getServer()` (ID-only), `getServerBySlug()`, `getServerOrThrow()`, `getAllServers()`, `getOfficialServers()`, `searchServers()`, `getServersByCategory()`, `getCategories()`, `findServerByCommand()`, `resetRegistry()`, `loadFromPath()`, `loadFromEntries()`, `getServersByRegistry()`, `searchServersInRegistry()`, `getAllMetrics()`, `getServerMetrics()`, `getRawServerData()`, `getServersSortedBy()`. Caches sorted arrays for performance. Re-exports `generateSlug` from `id-mapping.ts` |
| `src/enrich.ts`              | GitHub enrichment: maps GitHub topics to getmcp categories, infers runtime from registry type/language, fetches GitHub repo info, builds enrichment metadata                                                                                                                                                                                                                                                                                                                                                                                                                |
| `src/enrichment-types.ts`    | Zod schemas for enrichment (`GetMCPEnrichment` with `isOfficial` flag) and metrics (`GetMCPMetrics` with GitHub/npm/PyPI/Docker sub-schemas); category and runtime enums                                                                                                                                                                                                                                                                                                                                                                                                    |
| `src/extract-config.ts`      | Extracts canonical `ServerConfig` from official MCP registry format; transforms `packages[]`/`remotes[]` into `StdioServerConfig` or `RemoteServerConfig`                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `src/fetch-metrics.ts`       | Metrics fetchers for the sync pipeline: GitHub stars/forks, npm weekly downloads, PyPI monthly downloads, Docker Hub/GHCR pulls; includes retry logic and concurrency control                                                                                                                                                                                                                                                                                                                                                                                               |
| `src/id-mapping.ts`          | Slug generation from official reverse-DNS names (e.g. `io.github.owner/name-mcp` → `name`); `generateSlug()` exported publicly, `generateSlugs()` and `resolveCollisions()` kept for sync pipeline only                                                                                                                                                                                                                                                                                                                                                                     |
| `src/official-api-types.ts`  | Zod schemas matching the official MCP registry API format: `OfficialServer`, `OfficialPackage`, `OfficialRemote`, response wrappers                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `src/transform.ts`           | Transforms official MCP registry entries into `InternalRegistryEntry` format: `id` = official reverse-DNS name (`server.name`), `slug` = URL-friendly derived name, plus `isOfficial` flag and optional `registrySource`. Used by the registry engine, CLI, and web                                                                                                                                                                                                                                                                                                         |
| `scripts/sync.ts`            | Sync pipeline: fetches from official MCP registry API with `version=latest` and `updated_since` for incremental sync, enriches with GitHub data, fetches metrics, stamps official status from curated list, writes `data/servers.json`. Supports `--full` flag to force complete re-sync                                                                                                                                                                                                                                                                                    |

## `@getmcp/web` (`packages/web/`)

Astro static site (`astro.config.mjs`, `output: "static"`, `build.format: "file"`). Pages are `.astro` components; interactive parts use small module scripts (`scripts/`). React is used only for the `/servers` `SearchBar` island (`client:*`) and its children. `packages/web/scripts/build.ts` runs `astro build` and then `packages/web/scripts/measure.ts` (size report against hosting limits). Paths in the table are relative to `packages/web/src/`.

| File                                                              | Purpose                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pages/index.astro`                                               | Homepage without React islands: hero (`AsciiArt.astro` + `AnimatedCommand.astro`), stats, format showcase, CLI showcase (`CliShowcase.astro`), popular servers, categories, supported apps                                                                                               |
| `pages/servers/index.astro`                                       | Server directory: passes every server (minimal fields) to the `SearchBar` island                                                                                                                                                                                                         |
| `pages/servers/[id].astro`                                        | Server detail page, one per unique slug (`getStaticPaths` via `lib/server-paths.ts`): hero, `PackageManagerCommand` + `ConfigViewer` (static `.astro`, no islands), sidebar, related servers                                                                                             |

| `pages/guides/index.astro`                                        | Guides index listing all 19 app-specific setup guides                                                                                                                                                                                                                                    |
| `pages/guides/[app].astro`                                        | 19 app-specific MCP setup guides                                                                                                                                                                                                                                                         |
